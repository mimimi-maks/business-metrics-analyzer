# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Введение
Данный документ описывает бизнес-требования к учебному проекту «Business Metrics Analyzer», разрабатываемому в рамках дисциплины «Проектирование и разработка бизнес-ориентированного программного обеспечения».

## 2. Бизнес-цель
Автоматизация процесса расчёта и визуализации ключевых показателей эффективности (KPI) предприятия для упрощения принятия управленческих решений на основе данных о выручке и затратах.

## 3. Заинтересованные стороны
- Руководитель предприятия
- Бизнес-аналитик
- Разработчик

## 4. Функциональные требования (FR)
- Приложение должно загружать данные о выручке и затратах за период.
- Приложение должно рассчитывать среднюю выручку за выбранный период.
- Приложение должно рассчитывать рентабельность (отношение прибыли к выручке).
- Приложение должно выводить таблицу с исходными данными.
- Приложение должно строить график динамики выручки (с использованием библиотеки matplotlib).
- Приложение должно обрабатывать ситуацию, когда выручка равна нулю (возвращать 0.0 вместо деления на ноль).

## 5. Нефункциональные требования (NFR)
- Язык разработки: Python 3.10+.
- Кроссплатформенность: работа на Windows, macOS, Linux.
- Запуск приложения осуществляется из командной строки.
- Код должен быть читаемым и документированным.
- Зависимости должны быть зафиксированы в файле `requirements.txt`.

## 6. Ограничения
- Проект является учебным и не предназначен для промышленной эксплуатации.
- Входные данные вводятся вручную или из простых CSV-файлов (без подключения к базам данных).

## 7. Критерии успеха
- Корректный расчёт KPI на тестовых данных.
- Успешный запуск программы без ошибок.
- Наличие оформленного README.md с инструкцией по запуску.
- Возможность командной работы через Git и GitHub.
