# Описание ключевых Use Cases

## UC-03. Формирование отчёта

| Поле | Значение |
|---|---|
| **Название** | Формирование отчёта |
| **Основной актор** | Аналитик |
| **Цель** | Получить отчёт с KPI за выбранный период |
| **Предусловия** | Пользователь авторизован; данные о продажах загружены |
| **Триггер** | Пользователь выбирает команду «Сформировать отчёт» |
| **Основной поток** | 1. Пользователь открывает раздел отчётов. 2. Выбирает период анализа. 3. Нажимает «Сформировать отчёт». 4. Система рассчитывает KPI. 5. Система отображает отчёт с выручкой, средним чеком, конверсией и рентабельностью. 6. Пользователь просматривает результат. |
| **Альтернативный поток** | Если за выбранный период нет данных, система сообщает «Нет данных за выбранный период» и предлагает выбрать другой период. |
| **Постусловия** | Отчёт сформирован и доступен для просмотра и экспорта в Excel |

## UC-04. Загрузка данных о продажах

| Поле | Значение |
|---|---|
| **Название** | Загрузка данных о продажах |
| **Основной актор** | Менеджер по продажам |
| **Цель** | Передать системе исходные данные для автоматического расчёта KPI |
| **Предусловия** | Пользователь авторизован и имеет право загрузки; подготовлен Excel-файл |
| **Триггер** | Пользователь выбирает команду «Загрузить данные» |
| **Основной поток** | 1. Пользователь открывает форму загрузки. 2. Выбирает Excel-файл. 3. Нажимает «Загрузить». 4. Система проверяет формат и обязательные поля. 5. Система импортирует корректные данные. 6. Система автоматически рассчитывает KPI и сообщает об успешной загрузке. |
| **Альтернативный поток** | Если файл имеет неверный формат или не содержит обязательных полей, система отменяет импорт и показывает описание ошибок. |
| **Постусловия** | Корректные данные сохранены, KPI пересчитаны, результат загрузки показан пользователю |
